# 预判 · ANTICIPATE

一个**读心博弈**：对手每一步都把自己的猜测公开写在棋盘上，然后等你走。

你踩进它圈出的格子，掉一格血。

它不是随机猜的——它记你的习惯。你越有章法，它越准。

![screenshot](screenshot.png)

## 玩法

- `↑ ↓ ← →` 或 `WASD` 移动，也可以直接点相邻格。
- 每回合它会用粉色角标圈出一个格子——那是它赌你下一步会去的地方。
- 踩进去：掉 1 格血。躲开：安全。
- 琥珀色光点是唯一的目标：吃到 +1 分、**回 1 格血**；光点熄灭，掉 1 格血。
- 收集 8 枚之后，它开始同时圈**两个**格子。
- 血归零结束。结算页会告诉你它这场读对了你多少步——那个百分比就是你的"可预测度"。

## 它是怎么"读"你的

它不是一个脚本化的假 AI，而是一个在线学习器：

```
上下文 = (你在哪个 3×3 区域) × (光点在你哪个方向) × (你上一步往哪走)
每个上下文维护 4 个方向的出现次数
预测 = 取次数最高的方向
```

- **开局**：它有一个很弱的先验（"人大概会朝光点走"），所以第一局它看起来就像懂你。
- **中局**：它开始学你躲避的偏好——你总是往左绕，它就把左边的格子圈起来。
- **后期**：每收集 8 枚光点，它的圈数 +1。到两个圈时，四个方向里有两条被它堵住，你必须在"绕远"和"挨一下"之间做选择。

结算页的命中率，是它对你的预测准确率。**这个数字越低，说明你越难被读。**

## 设计笔记

三个刻意的决定：

1. **血不是惩罚，是货币。** 吃到光点回血，意味着"挨一下换一个光点"是一笔可以做、也常常值得做的交易。游戏不是在考你反应，是在考你愿不愿意付这笔钱。
2. **命中后它失明一回合。** 早期版本里，它会在走廊里连续点你的名，三回合掉光血——那不是博弈，是处决。现在你挨一下就能获得一步的自由，用于脱身或抢光点。
3. **标记永远是公开的。** 没有隐藏信息，没有运气成分。你输掉，是因为你的走法真的被算到了。这比"它猜对了但没告诉你"要诚实得多。

## 本地运行

没有构建、没有依赖、没有网络请求。直接双击 `index.html`，或者：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 技术

单文件 HTML + Canvas，约 600 行原生 JavaScript。没有框架、没有图片资源、没有音频文件——音效用 WebAudio 现场合成。
